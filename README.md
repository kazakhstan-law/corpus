# Корпус законодательства Республики Казахстан

**Не выкачивайте портал — клонируйте зеркало.** Здесь уже лежит то, за чем
обычно идут на портал парсером: полный текст каждой редакции каждого акта, в
Markdown, с историей изменений в истории git. `git clone` занимает минуты и не
создаёт на портале нагрузки. Свой парсер занимает дни и создаёт.

**Неофициальная копия.** Официальный источник — Единая система правовой
информации, ЕСПИ (`law.gov.kz`). Каждый файл несёт ссылку на свою страницу на
портале в ключе `source` front-matter блока.

Собрано из базы: **2026-09-12**.

## Как клонировать

Чаще всего нужен только `codes` — клонируйте его напрямую:

```
git clone https://github.com/kazakhstan-law/codes.git
```

Зонтичный репозиторий собирает все части сразу, и у этого есть две цены,
о которых лучше знать заранее, чем обнаружить: `git clone` без
`--recurse-submodules` не выкачивает содержимое вообще, а история и diff
через границу репозитория не работают.

```
git clone --recurse-submodules https://github.com/kazakhstan-law/corpus.git
```

## Что означает указатель субмодуля

Ничего про прошлое. Истории частей расходятся — дата, в которую в этой части
ничего не менялось, не даёт в ней коммита, — поэтому указатель субмодуля это
утверждение о том, где находится HEAD части сейчас, и только.
